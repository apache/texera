This tool converts a Python Jupyter Notebook into a Texera workflow using LLM capabilities. After you submit a notebook, the LLM service generates a corresponding Texera workflow. The conversion time depends on the notebook's complexity and can take 1-5 minutes. Once generation finishes, you are taken to the new workflow, which opens with:

  1. The generated workflow ready to use (Note: you will still need to upload the dataset and connect it to the workflow).
  2. A floating Jupyter window containing the uploaded notebook for reference.

Generation runs here after you submit. Please keep this window open while you wait.
